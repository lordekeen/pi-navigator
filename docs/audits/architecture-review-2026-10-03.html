Problem

  • locality: the mtime protocol lives beside the state it reads
  • interface: callers stop parsing path strings
  • the commit: prefix protocol disappears
  • one race guard instead of two

  • locality: #117-class bugs cannot return silently
  • one place for reload, reflow and race policy
  • fewer reads per image load
  • tests stop mutating pi-tui globals
