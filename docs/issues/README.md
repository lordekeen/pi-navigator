# pi-navigator Issue Tracker

Tracking findings, bugs, and enhancements identified during code reviews and QA audits.

**This directory has one index:** [issues_index.md](issues_index.md) — full metrics,
per-issue status, categorization, and the lifecycle workflow.

One file per issue, `NNN-<slug>.md`, is the record of truth; the index is the only
aggregate. A second, hand-maintained table used to live here (#001–#008 plus #069 —
9 of 115 issues, and referenced from nowhere) and was retired in
[#115](115-test-count-drift-and-index-bookkeeping.md): a partial duplicate of the
index can only drift.
